# MindMesh

MindMesh is an AI/ML workspace designed to help users turn tabular data into useful predictions. Users will be able to upload datasets, prepare data, train and compare models, save their results, and make predictions from a clean dashboard.

## Planned features

- Separate accounts and workspaces for each user
- CSV and Excel dataset uploads
- Guided data preparation and model training
- Classification and regression model comparison
- Saved models for single and batch predictions
- Performance reports and an **Ask MindMesh** assistant for exploring datasets and understanding results

## Project status

MindMesh is currently in development. The goal is a working application with a connected frontend, backend, database, and machine learning pipeline. Demo datasets used during development are synthetic and clearly identified as such.

## Goal

Make the full machine learning workflow accessible in one place, from the first dataset upload to an explainable prediction.
